# PrivyCode VS Code Extension

Privacy-First AI Coding Companion powered by SovereignForge.

## Features
- **In-Memory AST Symbol Graph**: Fast code navigation and cross-file symbol indexing in RAM.
- **Fill-in-the-Middle (FIM)**: Ultra low-latency ghost text code autocompletion.
- **Zero-Retention Multi-File Chat**: Sidebar conversational assistant with `@file` and `@symbol` context injection.
- **Inline Code Refactoring**: Seamless Cmd+I inline code editing and unified diff application.

## Configuration
- `privycode.apiUrl`: SovereignForge Gateway URL (default: `http://localhost:8000`)
- `privycode.apiKey`: API Key for authentication (e.g. `sk_live_...`)
- `privycode.model`: Selected AI model (e.g. `qwen-2.5-coder-32b`)
